# Technology & Internet

## Vocabulary
- **Application (App)**: A computer program designed to perform a group of coordinated functions.
- **Browser**: A program with a graphical user interface for displaying HTML files, used to navigate the World Wide Web.
- **Download**: Copy data from one computer system to another, typically over the Internet.
- **Password**: A secret word or phrase that must be used to gain admission to something.
- **Device**: A piece of mechanical or electronic equipment made for a particular purpose.

## Grammar Focus: First Conditional for Possible Situations
We use the First Conditional to talk about things which might happen in the future if a condition is met.
- *If you download the app, you will get a discount.*
- *If I forget my password, I won't be able to log in.*

## Sentence Making Prompt
Describe a situation using the internet or a device with the vocabulary word **Download** and the **First Conditional**.
